# Paramedic Exam 1 Practice

An interactive, randomized study test for:

- Chapter 1: Advanced Prehospital Emergency Medicine
- Chapter 2: EMS Systems
- Chapter 3: Roles and Responsibilities of the EMS Practitioner
- Chapter 4: EMS Safety and Wellness
- Chapter 5: EMS Research
- Chapter 20: Emergency Pharmacology (pages 493-521)
- Medication Sheet 1

The app includes more than 300 base questions, adjustable chapter weighting, a selectable test length, a hint for every question, immediate explanations, a searchable glossary, and a medication reference.

## Live site

GitHub Pages deploys automatically from `main`:

`https://kadenlarussa.github.io/exam-1-study-guide/`

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run build:pages
```

Medication doses reproduce the provided course study sheet and are for studying only. Always follow current local protocols and medical direction in practice.
